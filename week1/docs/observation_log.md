## 运行修改说明

### 修改 WiFi / 服务器地址
1. 编辑 `sdkconfig.defaults` 修改配置
2. 删除 `build/` 目录和 `sdkconfig` 文件
3. 重新 `idf.py build && idf.py flash`

### 修改上传频率
- `CONFIG_UPLOAD_INTERVAL_MS` 范围 1000~60000 ms
- 修改后重新编译烧录

### 切换量程
- 代码中 `qma7981_init(QMA7981_RANGE_8G)` 可改为 `2G/4G/16G/32G`
- 加速度单位自动换算为 mg
